# AEL-accelerated-depreciation-investor-patience
Replication code for "Can Capital Investment Tax Incentives Foster Investor Patience? Evidence from China's Accelerated Depreciation Reform" (Applied Economics Letters submission).

Author: Xu Li, Central University of Finance and Economics.

The replication code will be released in this repository upon acceptance of the paper. The underlying firm-level data are obtained from the China Stock Market & Accounting Research (CSMAR) database (https://data.csmar.com/) and are not redistributed here.
